# Rebalance · 수동 자산배분

규칙 빌더 및 자동 전략 판정을 제거하고 사용자가 직접 계획하는 자산배분 앱입니다.

## 화면

- **이번달**: 전략당 카드 하나, 모바일 1열/PC 2열. 기준일 종가의 원화 환산 평가액과 전략 내 종목 비중.
- **리밸런싱**: 전략명·티커·종목명·보유수량·통화·종가·평가액·현재/목표 비중·10개월 SMA·12개월 수익률. 목표는 직접 입력합니다.
- **주문안**: 보유 또는 후보 종목의 매수/매도 수량을 반영합니다. 새 종목은 검색하여 후보로 등록한 뒤 매수합니다.
- **기록**: 평가 스냅샷을 확정하고 각 시트를 CSV/TSV로 출력합니다.
- **설정**: 전략 추가/변경/삭제, 종목 검색/추가/삭제, 최종 보유수량과 목표비중 입력, CSV/백업 복원.

## GitHub에 업로드

1. 새 저장소를 만들고 ZIP을 압축 해제합니다.
2. `asset-rebalance-manual` 폴더 **안의 파일과 하위 폴더**를 저장소 루트에 업로드합니다. ZIP 자체를 코드로 업로드하지 마세요.
3. Streamlit Community Cloud에서 저장소와 `streamlit_app.py`를 선택합니다.
4. 기존 앱의 Secrets를 새 앱에 설정합니다. 비밀번호/시크릿은 저장소에 커밋하지 마세요.

## 관리 규칙

전략 추가 시 원화 현금(CASH) 항목이 생성됩니다. 후보는 수량 0으로 추가합니다. 중복 전략과 중복 종목은 차단합니다. 국내 수량은 정수, 미국 수량은 소수점 입력이 가능합니다. 음수와 비정상 숫자를 차단하고 목표비중은 0~100%로 제한합니다.

설정에서는 작성 중인 목표 합계가 100%가 아니어도 저장하고 경고합니다. 리밸런싱 화면의 최종 목표 적용은 합계 100%를 요구합니다. 보유 자산이 있는 종목/전략은 수량과 현금을 0으로 정리한 뒤 삭제합니다. 전략명 변경과 삭제는 과거 기록을 변경하지 않습니다.

**설정의 보유수량**은 최종 잔고이고, **주문안의 매매수량**은 잔고에 더하거나 뺄 수량입니다. 앱은 실제 증권 주문을 전송하지 않습니다. CASH는 거래대금으로 자동 조정하지 않으며 실제 원화 잔액을 직접 입력합니다. 설정에서 수량이나 종목을 변경한 뒤에는 종가를 다시 조회하세요. 주문안의 매수·매도 반영은 조회된 종가를 유지하면서 평가액과 비중을 즉시 재계산합니다.

## 가격과 검색

기준일 이전 마지막 종가와 원/달러 환율을 사용합니다. 7일 초과된 가격은 오류로 표시하며 일부 가격이 없으면 전략 총액과 비중을 확정하지 않습니다. 종가/SMA는 거래통화, 평가액은 원화입니다. 지표는 완료된 월의 비수정 월말 종가로 계산합니다. 월중에는 당월을 제외하고 충분한 월별 자료가 없으면 지표를 비웁니다.

미국 종목명/티커는 Yahoo 검색, 국내 한글 종목명/티커는 KRX 목록 검색도 사용합니다. 서비스 연결이나 검색 결과가 없을 때 직접 입력할 수 있습니다. `.KQ` 티커는 유지해 코스닥을 조회합니다. 검색 응답과 실제 시세 조회는 외부 서비스 상태에 따라 달라집니다.

## Google Sheets

`apps_script/Code.gs`는 원본과 동일합니다. 설정은 `docs/SHEETS_SETUP.md`를 참고하세요. `SHEETS_WEBAPP_URL`, `SHEETS_SECRET`, `APP_PASSWORD`를 Streamlit Secrets에 지정합니다. 기존 원장 형식/8개 탭, 저장 충돌 확인과 저장 후 재조회 검증을 유지합니다. Strategies의 과거 규칙은 호환용 데이터이며 실행하지 않습니다.

## 화면 개선 v2

가격 열(종가, 10개월 SMA 등)은 천 단위 구분자로 표시합니다. 리밸런싱 표에서 SMA는 종가 바로 오른쪽에 있습니다. 주문안은 보유수량·현재 평가액·전략 내 현재 비중을 작은 요약 카드로 표시합니다. 매매 전 종가 조회가 필요하며 매매 후에는 동일 종가로 모든 비중을 다시 계산합니다. 이번달에는 총 평가액과 전략 카드 사이에 원화 평가액 기준 자산 분류 도넛 차트를 표시합니다. 설정에서 자산 분류를 수정할 수 있습니다.

## 검색 개선 v3

QQQ 등 주요 티커는 기본 목록에서 외부 검색 없이 선택합니다. 정확한 기본 티커는 시장 선택이 다르더라도 실제 시장으로 안내합니다. 다른 미국 티커는 개별 정보 조회와 텍스트 검색을 병행하고, 국내 종목은 ETF/KR와 KRX 목록을 모두 검색합니다. 검색 결과는 장기 캐시하지 않으며 연결 실패를 검색 결과 없음으로 숨기지 않습니다. 기본 목록의 정보는 실시간 시세가 아니며 시세 조회는 외부 서비스 제한을 받을 수 있습니다.

## 검색 개선 v4

현재 전략에 없는 임의 티커도 검색합니다. 검색 방식에서 티커를 선택하면 영문 티커는 미국, 숫자 티커는 국내 시장으로 인식합니다. MAGX, NVDL 등을 별도 목록 등록 없이 개별 종목 정보와 검색 서비스로 조회합니다. 종목명 검색은 선택한 시장을 따릅니다. 외부 정보 조회 실패 시 입력 티커를 정보 미확인 후보로 표시하며 실제 종목 존재를 확인한 것으로 간주하지 않습니다. 등록 후 종가 조회가 성공해야 주문안에서 매매수량을 반영할 수 있습니다.

## 디자인 개선 v5

본문과 보조 글자의 대비를 높이고 숫자 정렬과 여백을 통일했습니다. 총 평가액 카드의 높이를 줄이고 종목 카드에 평가액/비중 열 제목을 추가했습니다. 작은 모바일 화면에서는 종목명과 숫자 행을 나누고 주문 요약을 세로로 배치합니다. 분류 차트는 퍼센트와 범례를 분리해 긴 이름 겹침을 줄였습니다.

## 표 개선 v6

PC 리밸런싱 조회는 사용자 정의 HTML 표로 제공하며 헤더 배경, 행 강조, 숫자 우측 정렬, 천 단위 구분자를 적용합니다. 모바일에서는 동일 정보를 종목 카드로 보여줍니다. 목표비중은 티커·종목명·현재비중·목표비중의 작은 편집 표에서 변경합니다. 사용자 입력은 HTML에 출력하기 전에 이스케이프합니다. 넓은 조회 표는 PC에서 가로 스크롤을 지원합니다.
