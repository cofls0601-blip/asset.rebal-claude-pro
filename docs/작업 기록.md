- **이번달:** 총 평가액, 자산 분류 도넛 차트, 전략별 카드(평가액·비중).
- **리밸런싱:** 종목별 수량·종가·평가액·현재/목표 비중·10개월 SMA·12개월 수익률을 보여 준다. 목표 비중은 직접 입력한다.
- **주문안:** 매수·매도 수량을 넣으면 같은 종가로 비중을 다시 계산한다. 새 종목도 검색해서 추가할 수 있다.
- **기록:** 평가 스냅샷을 확정하고 시트별로 CSV·TSV를 내보낸다.
- **설정:** 전략과 종목 관리, 보유 수량·목표 비중 입력, 백업과 복원.
- **Google Sheets:** Apps Script 웹앱으로 8개 탭을 읽고 저장한다. 저장 충돌을 확인하고, 저장 후 다시 읽어서 검증한다.
- **월말 점검(2026-10-26 추가):** `streamlit_app/rules.py`
  - GSM → LAA → SSO → ISA 순서로 카드를 보여 준다. 카드마다 판정 한 줄, 근거 표, 현재/제안 비중이 있다.
  - 「목표 비중에 반영」을 누른 전략만 목표 비중이 바뀐다. 매매 수량은 주문안에서 직접 넣는다.
  - EM 등 다른 전략은 "판정 없음"으로 표시한다. 판정에 필요한 자료가 없으면 "계산 불가"와 이유를 보여 준다.
  - 전략은 **전략 코드(LAA·GSM·SSO·ISA)**로 알아본다. 시트의 전략 이름이 다르면 판정하지 않는다.
  - 종목 찾기: LAA 필터 종목은 역할 「필터」, 없으면 종목명에 나스닥·유로가 들어간 종목이다. SSO·ISA 매수 종목은 비현금 종목 하나이고, 여러 개면 역할 「레버리지」나 종목명으로 찾는다. 설정 > 종목 표에 「역할」 열을 추가했다.
  - SSO·ISA는 이미 실행한 단계를 다시 사지 않도록, 현재 비중이 단계 목표보다 5%p 이내로 낮으면 "이미 실행됨"으로 본다.

## 실행·테스트하는 법

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
python -m unittest discover -s tests
python -m backtest.run   # 백테스트 (tabulate 필요)
```

- Streamlit Secrets에 `SHEETS_WEBAPP_URL`, `SHEETS_SECRET`, `APP_PASSWORD`가 필요하다. 저장소에는 넣지 않는다.
- 이 클라우드 컨테이너에서는 시세 사이트가 막혀 있어서 실시간 가격을 확인할 수 없다. 테스트는 가짜 응답으로만 돈다.

## 사용자가 알려 준 규칙과 결정 (2026-10 인터뷰)

자세한 내용은 [전략 명세.md](전략%20명세.md)에 있다.

- 판정 대상은 GSM, LAA, SSO, ISA뿐이다. EM, 금 현물, 별도 현금은 판정하지 않는다.
- 판정 결과는 제안만 한다. 반영은 사용자가 결정한다.
- 12개월 수익률과 SMA는 가격만으로 계산한다(배당 제외).
- 고점 대비 하락률은 52주 최고 종가 기준이고, ETF 가격(QQQ·SPY)으로 계산한다.
- SSO와 ISA의 단계형 규칙은 사용자가 채택했다(명세 참고).
- LAA의 유럽 필터는 TIGER 유로스탁스배당30으로 판정한다.
- 금 현물은 g 수(시트에 입력) × 국제 금시세 × 환율로 추정하고, 분류는 "금"이다.
- 별도 현금은 총자산과 현금 분류에는 넣지만, 판정에는 쓰지 않는다.
- 일반계좌 1은 신흥국 주식으로 분류한다. 수량이 실제와 다를 수 있다.
- 증권사 계좌 연결은 하지 않는다.
- 월말 기준일은 사용자가 사이드바에서 고른다. 그날 종가를 그달 월말 종가로 보고 SMA·12개월 수익률을 계산한다.
- 화면은 증권사 "총자산" 화면 같은 카드형(휴대폰 1열, PC 2열)이다. 변동은 전일 대비와 지난달 기록 대비를 보여 준다.
- 결과 검증은 증권사 앱 총액과 눈으로 비교하는 방식이다. 앱에 대조 칸을 두면 좋다.
