# 새 설계안 (2026-11-02 제안, 2026-11-03 사용자 승인 · 1단계 구현)

지금 화면(이번달·월말 점검·리밸런싱·주문안·기록·설정)은 기능을 하나씩 덧붙여 온 결과다.
이 문서는 "사용자가 이 앱으로 하려는 일"에서 다시 출발한 설계안이다. 계산 코드(시세·평가·판정·Sheets 저장)는 테스트가 있으므로 그대로 쓰고, 화면과 흐름만 새로 짠다.

## 1. 사용자가 이 앱으로 하려는 일

| 언제 | 하려는 일 | 지금 겪는 불편 |
|---|---|---|
| 아무 때나(휴대폰) | 내 돈이 지금 전부 얼마인지, 계좌별로 얼마인지 본다 | 증권사 앱을 하나씩 열어야 했다 |
| 월말 하루 | 규칙대로만 판단한다(해석 금지): GSM → LAA → ISA (12월 EM) | 메뉴 세 곳(월말 점검·리밸런싱·주문안)을 오가야 하고, 비중(%)을 주식 수로 직접 바꿔야 한다 |
| 월말 하루 | 증권사 앱에서 주문하고, 체결 후 수량을 앱에 맞춘다 | 수량을 종목마다 손으로 고친다 |
| 월말 하루 | 결과가 맞는지 증권사 총액과 대조하고, 6개 분류로 기록한다 | 기록·저장 버튼이 흩어져 있다 |
| 연 1회 | 내년 전략을 정한다(백테스트) | 앱 밖에서 한다(그대로 둔다) |

원칙: 규칙만 실행한다. 앱은 제안하고 사용자가 정한다. 증권사 계좌는 연결하지 않는다. 휴대폰이 먼저다.

## 2. 화면 구성: 메뉴 6개 → 3개

화면 위쪽 탭(휴대폰에서 사이드바를 열 필요 없음): **홈 · 월말 리밸런싱 · 내 자산**

### 홈 — "지금 얼마인가"
- 총자산(전일 대비, 지난달 기록 대비) → 계좌 카드(누르면 종목).
- 맨 위 한 줄 알림: "이번 달 리밸런싱 전" / "리밸런싱 완료(10-30)" / "수량 확인이 필요한 계좌 1개(일반계좌 1)".
- 가격은 앱을 열면 자동으로 불러온다(「종가 조회」 버튼 없음). 기준일은 오늘.

### 월말 리밸런싱 — 한 줄로 이어지는 4단계
1. **기준일**: 오늘 또는 직접 고른 날(29일·30일 등). 고르면 가격을 바로 불러온다.
2. **할 일 확인**: 판정하는 계좌만, 점검 순서대로 카드가 나온다. 카드에는 판정 한 줄과 함께 **"매수 TIGER 미국S&P500 12주 / 매도 TIGER 미국나스닥100 8주"처럼 주식 수**가 바로 보인다(국내는 정수로 내림, 미국은 소수 허용 여부에 따름). 할 일이 없으면 "이번 달 할 일 없음". 근거 숫자(SMA·수익률)는 접어 둔다.
3. **체결 입력**: 증권사에서 주문한 뒤, 주문마다 「그대로 체결」 또는 실제 수량 입력. 누르면 보유 수량이 바뀐다.
4. **마감**: 계좌별 증권사 총액을 넣어 대조 → 「이번 달 마감」 한 번으로 평가 기록 + Sheets 저장.

중간에 앱을 닫아도 단계가 남아 있다(다음 날 체결분 이어서 입력).

### 내 자산 — "수량과 전략 관리"
- 계좌별 보유 수량 빠른 수정(일반계좌 1처럼 자주 바뀌는 계좌용). 금 현물은 g 수.
- 계좌마다 지금 쓰는 전략을 **쉬운 말 한 줄**로 보여 준다(예: "QQQ가 10개월 평균 위면 나스닥 2배 100%, 아래면 현금"). 2026 ↔ 2027 전환은 여기서 한 번.
- 종목 추가·삭제, 백업·복원, 원장 미리보기는 맨 아래 「고급」으로 접는다.
- 지난 기록(월별 총자산 추이, 6개 분류 비중)도 여기서 본다.

## 3. 지금과 달라지는 점

- 비중(%) 대신 **주식 수**로 할 일을 보여 준다 → 계산 단계가 사라진다.
- 판정하지 않는 계좌는 리밸런싱 화면에 아예 나오지 않는다.
- 「종가 조회」, 「목표 비중에 반영」, 「평가 기록 확정」, 「Sheets에 저장」 같은 중간 버튼을 흐름 안으로 넣는다.
- Google Sheets 8개 탭 형식은 그대로 둔다(기존 원장 호환).

## 4. 만드는 순서(제안)

1. 월말 리밸런싱 4단계(가장 시간을 줄이는 부분) — 주식 수 계산 포함.
2. 홈 단순화(자동 가격 조회, 상태 알림).
3. 내 자산(빠른 수량 수정, 전략 한 줄 설명, 고급 접기).
4. 예전 메뉴 정리.

각 단계마다 테스트를 붙이고, Streamlit Cloud에서 사용자가 확인한 뒤 다음으로 간다.

## 5. 정해야 할 것(사용자에게 하나씩 묻기)

- ~~매수 금액이 현금보다 많으면?~~ → 매도 먼저, 그 돈까지 합쳐 살 수 있는 만큼만 매수하고 줄인 수량을 표시(사용자 결정 2026-11-03).
- 미국 종목 소수점 주문 허용 여부(계좌별).
- 아주 작은 매매(예: 비중 차이 1%p 미만)는 건너뛸지.
