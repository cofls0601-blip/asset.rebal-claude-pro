# 투자 성향

사용자가 직접 말한 내용(2026-11-09)과 그동안의 결정을 정리한다. 새 전략을 제안할 때 이 문서에 맞는지 먼저 확인한다.

## 사용자가 말한 것 (2026-11-09)

- 날마다 시장 흐름을 따라가며 차트를 분석하고, 하루에도 몇 번씩 거래하는 방식은 **원하지 않는다**.
- 종목 분석에 에너지를 쓸 자신이 없다.
- 그래서 **CAGR(연 수익률)과 MDD(최대 하락)를 기준으로 고른 자산배분 전략**을 운용한다.
- 레버리지도 **짧은 기간에 수익이 날 가능성이 높다고 보이면** 들어간다. 예: QQQ가 10% 넘게 빠지면 잠시 TQQQ로 옮겼다가 돌아온다.

## 그동안의 결정에서 보이는 것

- 규칙대로 실행한다. 시장 예측은 규칙에 넣지 않는다. 앱은 제안만 하고 반영은 본인이 정한다.
- 전체는 안정적으로, 작은 한 칸(ISA)은 레버리지로 공격적으로 둔다("레버리지가 없으면 재미없다", 2026-10-28).
- 2027 조합(F1)은 수익이 비슷하면서 최대 하락이 작은 쪽을 골랐다.
- 일반계좌는 매매를 줄여 세금을 미룬다.
- 별도 현금과 금 현물을 안전판으로 둔다.

## 전략을 제안할 때 지킬 것

- 확인은 월 1회(월말)가 기본이다. 매일 봐야 하는 규칙은 제안하지 않는다.
- 종목 고르기가 필요한 전략은 제안하지 않는다(ETF·지수 기준).
- 레버리지 규칙은 반드시 긴 하락장(2000~02, 2008)을 넣어 시험하고 결과를 함께 보여 준다. 2026 ISA "하락 시 레버리지 매수" 규칙은 2000~02년 대용치에서 -98%였다.

## 투자 원칙 (해가 바뀌어도 그대로 두는 것)

계좌별 구체 규칙은 해마다 [연도별 전략.md](연도별%20전략.md)에 적는다. 이 절은 그 규칙을 **고르고 바꾸는 기준**이다.

1. **최대 하락 한도: 전체 자산 기준 -20%** (사용자 결정 2026-11-09). 백테스트(2000~02, 2008 포함)에서 전체 최대 하락이 -20%를 넘는 조합은 제안하지 않는다. 2027 조합(F1)은 약 -15%로 한도 안이다.
   - 레버리지 계좌 하나가 크게 빠지는 것은 허용한다. 기준은 전체 자산이다.
2. **확인은 월 1회(월말).** 날마다 보거나 하루에 여러 번 거래해야 하는 규칙은 쓰지 않는다.
3. **종목 분석은 하지 않는다.** ETF·지수 기준 규칙만 쓴다.
4. **규칙은 1년에 한 번(11~12월)만 바꾼다.** 중간에 떠오른 아이디어는 기록해 두고 연말 점검 때 백테스트로 시험한 뒤 정한다.
5. **흔들릴 때는 규칙을 어기기 전에 먼저 숫자로 확인한다.** 그 상황이 과거에 어땠는지, 규칙을 지켰을 때와 어겼을 때 결과를 비교해 본다.
6. **실제 하락이 -20%에 가까워지면(-15%부터)** 규칙 자체를 바꾸지 말고, 다음 연말 점검 때 한도를 지키는 조합인지 다시 시험한다.
