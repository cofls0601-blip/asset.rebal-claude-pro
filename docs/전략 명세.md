# 전략 명세

사용자가 붙여 넣은 "전체 포트폴리오 운용 매뉴얼(요약본)"을 정리한 문서입니다.
실제 금액과 계좌번호는 저장소에 남기지 않기 위해 뺐습니다.

- 원칙: 해석하지 않고 규칙만 실행한다.
- 점검일: 월말 하루. 월봉 차트와 12개월 수익률 표를 준비한다.
- 실행 순서: **GSM → LAA 필터 → SSO → ISA → 끝**
- 기록: 현금 / 선진국 주식 / 선진국 채권 / 신흥국 주식 / 신흥국 채권 / 금, 이렇게 6개 분류로 Google Sheets에 남긴다.

## 전략 목록

| # | 코드(앱) | 계좌 | 역할 | 점검 주기 |
|---|---|---|---|---|
| 1 | LAA | 과세 연금저축 | 장기 코어 + 하락 방어 | 필터는 매월, 비중 복원은 분기 1회 |
| 2 | GSM | 비과세 연금저축 | 기동 / 회전 / 인출 대비 | 월 1회 |
| 3 | ISA | ISA | 이벤트 공격 슬롯 | 매월 트리거 확인 |
| 4 | EM | 일반계좌 1 | 장기 성장 베팅(국내 주식) | 리밸런싱 없음(연 1회 정도만 허용) |
| 5 | SSO | 일반계좌 2 | 상승 엔진(가변 레버리지) | 매월 트리거 확인 |
| 6 | (없음) | 금 현물 | 테일 리스크 헤지 | 매매 없음 |
| 7 | (없음) | 별도 현금 | 생활 안정, 전략 충돌 방지 | 투자 판단에 넣지 않음 |

## 1. LAA — 변형 LAA (과세 연금저축)

목표 비중

| 자산 | 비중 | 필터 |
|---|---|---|
| NASDAQ | 12.5% | 적용 |
| EuroStoxx50 | 12.5% | 적용 |
| S&P500 | 12.5% | — |
| MSCI World | 12.5% | — |
| 금 ETF | 25% | — |
| 미국 10년 국채 ETF | 25% | — |

규칙
1. 월봉 기준 10개월 SMA를 쓴다.
2. NASDAQ과 EuroStoxx50에만 필터를 적용한다.
3. SMA 아래면 해당 비중(12.5%)을 현금으로 옮긴다. 나머지는 유지한다.
4. 분기마다 목표 비중으로 복원한다. (비중 복원은 분기 말에만 한다.)

## 2. GSM — 글로벌 단순 모멘텀 (비과세 연금저축)

후보: S&P500, MSCI World, NASDAQ, TIGER 유로스탁스배당30, 현금

규칙
1. 필터: 월말 기준 월봉 10개월 SMA 위에 있는 자산만 후보로 남긴다.
2. 선택: 후보 중 12개월 수익률 1위를 고른다.
3. 배분: 80%를 투자하고 20%는 현금으로 둔다.
4. 예외: 모든 자산이 SMA 아래면 100% 현금으로 둔다.

## 3. ISA — 나스닥 레버리지 트리거

1. 평소에는 현금으로 대기한다.
2. NASDAQ이 고점 대비 약 -10% 하락하면 분할 매수한다.
3. 반등 구간에서는 보유한다.
4. 과열 시 축소할 수 있다(재량).

## 4. EM — 국내 주식 장기 보유 (일반계좌 1)

- 코스피 추종 ETF와 한국 대형주로 구성한다.
- 세금 때문에 매매를 최소화한다. 리밸런싱은 없고 연 1회 정도만 허용한다.

## 5. SSO — SSO + 현금 (일반계좌 2)

1. 기본 비율은 SSO 70%, 현금 30%이다.
2. S&P500이 고점 대비 -15~-20% 하락하면 현금의 절반을 투입한다.
3. 급등 후 과열 시 일부 현금화할 수 있다. 단, 월간 점검에서는 급등 판단을 하지 않는다(재량 최소화).
4. 평시에는 그대로 두고 매매를 최소화한다.

## 6. 금 현물 / 7. 별도 현금

- 금 현물: 매매 없이 보유한다.
- 별도 현금: 생활 안정용이다. 투자 판단에 넣지 않는다.

## 사용자와 확정한 판정 기준 (2026-10 인터뷰)

공통
- SMA: 완료된 월의 월말 종가 10개를 평균한다(앱의 기존 계산). 배당을 뺀 가격 기준이다.
- 12개월 수익률: **가격만** 쓴다(배당 제외). 사용자가 카카오증권 앱에서 보던 값과 같은 기준이다.
- 고점 대비 하락률: **최근 52주 최고 종가 대비 현재 종가**로 계산한다. 기준 가격은 ETF이다(나스닥=QQQ, S&P500=SPY).
- 앱은 판정 결과를 **제안만** 한다. 목표 비중 반영은 사용자가 버튼으로 결정한다.
- 판정 대상은 LAA, GSM, SSO, ISA뿐이다. EM, 금 현물, 별도 현금은 "판정 없음"이다.

LAA 실제 종목 (종목코드는 앱의 KRX 검색으로 확인할 것)

| 자산 | 종목 | 필터 | 분류 |
|---|---|---|---|
| NASDAQ | RISE 미국나스닥100 | 적용 | 선진국 주식 |
| 유럽 | TIGER 유로스탁스배당30 (EuroStoxx50 대신, 사용자 확인) | 적용 | 선진국 주식 |
| S&P500 | RISE 미국S&P500 | — | 선진국 주식 |
| MSCI World | KODEX MSCI선진국 | — | 선진국 주식 |
| 금 | ACE KRX금현물 | — | 금 |
| 미국 10년 국채 | KODEX 미국10년국채선물 | — | 선진국 채권 |

- 필터는 각 종목 자체의 가격으로 판정한다. 비중 복원은 분기 말(3·6·9·12월)에만 한다.

GSM 후보: TIGER 미국나스닥100, TIGER 미국S&P500, KODEX MSCI선진국, TIGER 유로스탁스배당30 (모두 선진국 주식)

SSO (SPY 52주 최고 종가 기준, 사용자 채택)

| SPY 하락률 | 목표 비중 |
|---|---|
| 평시 | SSO 70% / 현금 30% |
| -15% 이하 | SSO 85% / 현금 15% |
| -20% 이하 | SSO 92.5% / 현금 7.5% |
| 52주 고점 회복 | SSO 70% / 현금 30%로 복원 |
| 그 사이 | 현재 비중 유지 |

ISA (QQQ 52주 최고 종가 기준, 사용자 채택, 매수 종목: TIGER 미국나스닥100레버리지(합성))

| QQQ 하락률 | 목표 비중 |
|---|---|
| 평시 | 현금 100% |
| -10% 이하 | 레버리지 1/3, 현금 2/3 |
| -15% 이하 | 레버리지 2/3, 현금 1/3 |
| -20% 이하 | 레버리지 100% |
| 52주 고점 회복 | 현금 100%로 복귀 |
| 그 사이 | 현재 비중 유지 |

- "현재 비중 유지" 구간 때문에, 앱은 지금 현금 비중을 보고 이미 실행한 단계를 판단한다(같은 단계를 두 번 사지 않음).

분류와 기록
- 6개 분류: 현금 / 선진국 주식 / 선진국 채권 / 신흥국 주식 / 신흥국 채권 / 금
- 금 현물 → 금. 보유 g 수는 시트에 입력하고, 가격은 국제 금시세(GC=F) × 원/달러 ÷ 31.1035로 추정한다. 화면에 "국제 시세 기준 추정"이라고 표시한다.
- 별도 현금 → 현금. 총자산에는 포함하지만 전략 판정에는 쓰지 않는다.
- 일반계좌 1(EM) → 신흥국 주식. 매매가 잦아 앱 수량이 실제와 다를 수 있다("수량 확인 필요" 표시).

## 아직 정해지지 않은 점

- SSO가 미국 상장 SSO인지, 일반계좌 2의 현금이 원화인지 달러인지.
- 각 종목의 정확한 종목코드(앱 검색으로 확인).
